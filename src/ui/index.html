Appearance

Follow system uses Airlock when the system is dark and Light Modern when it's light. The chat pane follows along when claude.ai's own appearance setting is on Auto.

Terminal output

Keeps up to 5,000 lines per tab in a file only your account can read. Anything printed on screen, including secrets, is written to disk. Turning this off deletes the file.

Highlighted terminal text goes straight to the clipboard, as in PuTTY. It never goes to the airlock. Right-click for Copy, Paste and Send to Claude either way.

Double-copy

Copying the same text twice within 1.5 seconds, from the chat or a runsheet, sends it to the airlock and runs it in the terminal straight away, with no chance to check it first.

Sites with Auto-run on

    On these sites in the Web tab, a double-copy runs in the terminal. Only turn this on for sites you trust, because a page controls what it copies. It needs HTTPS.

    Runsheet folder

    Local Snippets folder

    Choose a git or synced folder to share snippets between machines. If two machines edit at the same time, the last save wins. History and the scratchpad always stay on this machine.

    Snippet repos

    Git repos on any host, each marked Team or Personal. The Snippets tab lists them all together, and can show just Team, just Personal or one repo. Each snippet is a Markdown file in the repo's snippets folder. Commits use the name and email given here, or your global git ones if they're blank.

    To sign in as a different GitHub account for one repo, put that account's username in the address, like https://username@github.com/owner/repo.git, and Git Credential Manager keeps its sign-in separate. For an SSH address, give the key file instead.

    Remotes

    Saves a new server's key to ~/.ssh/known_hosts without asking, as ssh's StrictHostKeyChecking=accept-new does. A key that has changed since is still refused.

    Remotes saved to a repo are Markdown files in its remotes folder, next to snippets. They never hold passwords or keys: a 1Password reference names a password without being one, and a saved password stays on this machine.

    Ask AI

    The command palette (⌘K on macOS, Ctrl+Shift+K elsewhere) asks this server to write commands. Any OpenAI-style API works: LM Studio, Ollama, llama.cpp. It's sent your question, the shell, the operating system and the terminal's folder, never what's on screen. Picking a command in the palette runs it, and ⌘↵ (Ctrl+Enter) puts it in the airlock instead. A command that deletes or overwrites data never runs from the palette: it always goes to the airlock for you to check.

    Inline suggestions

    Grey text after the cursor as you type: the rest of a command from this tab, then from the airlock's history. → accepts it. Only what's on the line runs, when you press Enter. Also the book button on the toolbar.

    The model in Ask AI finishes the line when you pause typing. It's sent the line, the shell, the operating system, the folder and this tab's last few commands. It never suggests anything for a command that deletes things. Also the spark button on the toolbar.

    Ctrl+Space opens the list in either style.

    Updates

    Asks GitHub's list of published releases every 6 hours, and shows a notice in the status bar when there's a newer version. Nothing about you or this machine is sent, and nothing downloads or installs on its own.

    Data folder

    Holds settings, history, the scratchpad and saved terminal output.
