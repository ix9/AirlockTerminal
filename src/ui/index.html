Airlock Terminal

Appearance

The chat pane follows along when claude.ai's own appearance setting is on Auto.

Terminal output

Keeps up to 5,000 lines per tab in a file only your account can read. Anything printed on screen, including secrets, is written to disk. Turning this off deletes the file.

Double-copy

Copying the same text twice within 1.5 seconds, from the chat or a runsheet, sends it to the airlock and runs it in the terminal straight away, with no chance to check it first.

Sites with Auto-run on

    On these sites in the Web tab, a double-copy runs in the terminal. Only turn this on for sites you trust, because a page controls what it copies. It needs HTTPS.

    Runsheet folder

    Snippets folder

    Choose a git or synced folder to share snippets between machines. If two machines edit at the same time, the last save wins. History and the scratchpad always stay on this machine.

    Snippet repos

    Git repos on any host. Each shows in the Team Snippets or Personal Snippets tab, and a tab with several repos lists them together. Each snippet is a Markdown file in the repo's snippets folder. Commits use the name and email given here, or your global git ones if they're blank.

    To sign in as a different GitHub account for one repo, put that account's username in the address, like https://username@github.com/owner/repo.git, and Git Credential Manager keeps its sign-in separate. For an SSH address, give the key file instead.

    Data folder

    Holds settings, history, the scratchpad and saved terminal output.
